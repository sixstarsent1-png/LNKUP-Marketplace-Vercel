# Phase 17 RFC — Organizer CRM Depth in App

## Why this phase

Organizer workflows still split between app and WordPress for deeper CRM operations. This phase expands in-app daily-use CRM while preserving WordPress as write authority for advanced tools.

## Scope

- Bring additional organizer vendor-list and invite workflows into app BFF.
- Expand event-scoped request triage and queue tooling.
- Improve organizer vendor profile drilldowns and action history.

## Out of scope

- No full wp-admin CRM replacement.
- No new capability model in WordPress.

## Key deliverables

- Live organizer Lists/Invites tabs (current partial/mock areas).
- Event-scoped request triage filters and batch-safe actions.
- Vendor relationship timeline summary panel.

## Success metrics

- More organizer review actions completed in app.
- Reduced organizer fallback to WordPress for routine triage.
- Faster request-to-decision cycle time.
