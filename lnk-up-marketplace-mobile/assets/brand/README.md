# LNKup brand assets

| File | Role |
|------|------|
| **`lnkup-logo.png`** | **Canonical official logo** (black / white / orange `#F58220`) |
| `lnkup-mark.svg` | SVG wrapper referencing the logo |
| `lnkup-mark-fg.svg` | Adaptive/splash foreground wrapper |
| `lnkup-mark-mono.svg` | Doc stub — mono PNGs come from `npm run icons` |

Regenerate store icons:

```bash
npm run icons
```

Do not replace `lnkup-logo.png` with Expo templates or the old geometric “LNK” mark.
